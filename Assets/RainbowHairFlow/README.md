# 彩虹发丝流光 0.3.0：使用教程与常见问题

适用：Unity 2022.3、Built-in 渲染管线、Windows VRChat 头像。
本工具生成普通网格、材质和动画资产，不需要客户端 MOD。

## 一、安装前确认

- 在测试场景或模型副本上操作，并保存现有编辑。
- 先按照发型作者说明装好头发，确认没有粉色材质、位置错误或原本就存在的穿模。
- 自动接菜单需要 VRChat Avatars SDK 和 Modular Avatar；分析、预览只依赖 Unity。
- 已验证环境：Unity 2022.3.22f1、SDK 3.10.6、MA 1.18.7、NDMF 1.14.8。
- 不支持 Quest、URP、HDRP。特殊着色器的透明、UV 动画等效果需要单独检查。

## 二、第一次使用

1. 导入插件 unitypackage。等待 Unity 编译完成，再打开 `Tools → 彩虹发丝流光 → 打开工具`。
2. 在 Hierarchy 展开头发，找到带 `Skinned Mesh Renderer` 或 `Mesh Renderer` 的对象，将它拖到窗口的“头发 Renderer”。不能只拖一个没有 Renderer 的发型总文件夹。
3. 确认“模型根节点”是整个头像的根对象。指定头发时，工具会按模型上方向换算头发的局部发根方向；之后更换模型根节点时，请重新指定一次头发或手动确认方向。
4. “源头发材质槽”从 0 开始计数。在 Renderer 的 Materials 列表里确认：Element 0 对应 0，Element 1 对应 1。选择实际头发所在槽，避免选到蝴蝶结、耳饰等。
5. 点击“分析发束”。这里的“发束”指网格中相互连通的一组面，不等于商品画出来的每一根细发丝。
6. 勾选想发光的发束；也可以设置“随机选择数量”和“随机种子”，点击“左右均衡随机选择”。同一模型和种子可复现选择；左右实际数量可能受网格可用发束限制。
7. 点击“动态预览”，转动 Scene 视角看前、后、左、右。完整观察几个流动周期；随机发束不会每时每刻同时发光。
8. 调整流速、流光宽度、亮度。修改发束、方向或路径模式后，再点击一次“动态预览”刷新结果。
9. “安装到菜单”可拖入希望放置开关的 `VRCExpressionsMenu`，例如身体设置/头发设置；留空时由 MA 安装到默认菜单位置。
10. 使用一个尚不存在的独立输出目录，例如 `Assets/RainbowHairFlowGenerated/MyHair01`，然后点击“生成并安装（默认关闭）”。
11. 保存场景。生成的开关名为“彩虹流光”，默认关闭，Bool 状态可记忆。

关闭工具窗口或点击“停止预览”会删除临时预览。预览本身不会永久安装到头像上。

## 三、粗细、速度和亮度怎么调

| 想调整的内容 | 参数或操作 | 范围/含义 |
|---|---|---|
| 光带更细或更宽 | 流光宽度 | 0.2–2 倍；默认 1，不修改头发网格粗细 |
| 流动更慢或更快 | 流速 | 0.1–3 倍；默认 1 |
| 更暗或更亮 | 亮度 | 0.1–2 倍；默认 1 |
| 更多位置出现流光 | 随机选择数量，或手动多选 | 增加被选发束，不等于加宽光带 |
| 换一批发束 | 修改随机种子后重新随机选择 | 不会更改原头发造型 |

安装前在工具窗口调。安装后，窗口滑条不会自动更新已经生成的资产：

- 找到输出目录内的 `On.mat`，在材质 Inspector 调整 `Width`、`Speed`、`Brightness`。
- `Preview time` 应保持 -1，使用正常动画时间；不要把某个固定预览时间保存进去。
- 若要重新选择发束或改变根梢标定，应先按记录还原，再重新分析并生成到新目录。

## 四、流动方向不对怎么校正

### 仅部分发束倒着流

在列表中找到那束，勾选“反向”，重新动态预览。Scene 中可以点击编号切换选择；“反向”在窗口列表中调整。

### 整体方向不对或横着流

优先使用 `SurfaceDistance`。检查“发根朝向（头发局部空间）”：它表示朝向发根的方向，不是流动方向。旋转过的 FBX 可能需要 Z 轴，而不是 Y 轴；可尝试对应轴的正/负方向并预览，不能照搬另一套头发的数值。

### 表面路径仍然不自然

尝试 `UV_V` 或 `UV_U`，再按需反向。只有 UV 布局与发根/发梢相匹配时才适合这两种模式；它们不是自动修复所有 UV 的按钮。

弯曲、卷曲、在同一网格中反复连接的发束，可能需要人工校正或先在建模软件中拆分。工具不会凭空识别贴图里画出的所有细发丝。

## 五、常见问题

| 现象/提示 | 排查和处理 |
|---|---|
| Tools 中没有入口 | 检查 Unity Console 是否存在 C# 编译错误；确认插件的 Editor 文件夹完整，等待编译结束。 |
| “请先指定头发” | 拖入具体带 Renderer 的对象，而不是总目录或 FBX 文件本身。 |
| 分析结果全是配饰 | 源材质槽或 Renderer 选错。重新选择后再分析。 |
| “至少选择一束头发” | 至少勾选一项，然后重新预览或安装。 |
| 只能识别一大束 | 源网格整体连成一片。可先试 UV 模式；想分别选择其中几缕，需要拆分连通结构。单纯切换 UV 模式不会增加可选择发束数。 |
| 根本看不到流光 | 检查是否有选择发束、是否开启动态预览或生成后的菜单开关；观察几个周期；转到选中发束实际所在侧；再适量增加数量/宽度/亮度。 |
| 看起来只是一片光，没有彩虹 | 先恢复流速、宽度、亮度为 1，降低过高亮度，并近距离看完整周期。发束太短或太细时，完整色段可能无法明显呈现。 |
| 出现矩形亮片、透明处也发亮 | 检查生成材质的 `Hair alpha mask` 和 `Separate alpha mask`。0.2 会继承常见 _MainTex 及 lilToon 独立 AlphaMask；特殊 Shader、顶点透明、多层混合、UV 动画并不全部支持。对照原材质，不要随意把遮罩清空为白色。 |
| 原头发就是粉色或位置错误 | 先修复原发型依赖或按作者说明重新安装。流光插件不会修复原发型的骨架适配或丢失 Shader。 |
| “源网格 UV7 已占用” | 工具为保护原数据而停止。不要直接清空 UV7；应检查原用途，必要时为测试制作经过确认的独立网格副本。当前版本没有自动选择其他 UV 通道的功能。 |
| “自动接入需要…SDK 和 Modular Avatar” | 安装缺失依赖后重试。VRCFury 本身不能替代当前插件的 MA 安装接口。 |
| “依赖版本不兼容，缺少字段…” | 记录字段名和 MA/SDK 版本，对照已验证环境；不要盲目修改头像参数来绕过。 |
| “请使用 Assets 下尚不存在的独立输出目录” | 换一个新目录名，不能直接覆盖已经存在的文件夹。 |
| “该头发已安装通用流光” | 使用对应 InstallRecord 还原，然后重新生成；不要重复往同一 Renderer 上叠装。 |
| 菜单开关没出现在原菜单资产里 | MA 在构建/模拟处理中合并菜单，不会直接改写作者的原菜单文件。检查头像下生成的 MA holder，以及其 Menu Installer 的目标菜单。 |
| 有多个同名开关 | 当前一次安装针对一个 Renderer。分别安装多个 Renderer 会各自产生同名开关，不会自动合并成整套发型的单一开关。 |
| 换发型后流光没了/错位 | 为新发型重新生成；其他动画若替换整个 Hair 网格，也可能覆盖生成结果。不要将旧发型的 Hair.asset 套到新发型上。 |
| “找不到原头发路径” | 检查模型根节点，以及安装后是否改过层级/对象名称。先恢复正确路径，再按记录还原，不要强行套用其他记录。 |
| “当前网格与记录不匹配” | 确认选的是这一次安装的记录，并检查其他工具是否替换过网格；为防止覆盖新编辑，插件会拒绝强制还原。 |

## 六、一套头发有多个对象怎么办

本版一次处理一个 Renderer、一个源材质槽。前发、后发、双马尾若分成多个 Renderer，可先在最显眼的一部分试用，其他部分按需分别操作。每次使用独立目录，保留各自撤销记录。

分别安装会产生多个开关；当前没有整套发型一键批量安装和合并开关功能。不要把多个对象误当作同一个网格直接覆盖。

## 七、如何撤销和修改安装

1. 停止预览，指定正确的模型根节点。
2. 将对应输出目录的 `InstallRecord.asset` 拖入“撤销记录”。
3. 点击“按记录还原原头发并移除开关”。
4. 确认原网格、原材质槽恢复，模型下对应的流光 MA holder 已移除，然后保存场景。

撤销不会自动删除输出目录，以免破坏其他引用。确认目录不再被任何模型使用后，再自行整理。不要先删 InstallRecord 再尝试撤销。

## 八、生成了什么、会有什么开销

- `Hair.asset`：源网格的克隆，增加 UV7 和效果子网格；保留原顶点、蒙皮、blendshape 及 UV0–6。
- `On.mat` / `Off.mat`：流光材质。
- `On.anim` / `Off.anim`、`Flow.controller`：开关动画和 FX 控制器。
- `Menu.asset`、`MenuInstaller.prefab`：菜单与 MA 配置。
- `InstallRecord.asset`：原网格/原材质和安装路径记录，用于还原。

每次安装增加一个效果材质槽，被选中的三角形再绘制一次；通常增加一次效果绘制。没有额外粒子或 PhysBone。新增 Bool 参数占用同步参数预算。

MenuInstaller.prefab 仅保存本次安装的 MA 配置，不能拖到其他发型就自动完成适配。网格、渲染路径和材料槽仍须由工具针对目标生成。

## 九、高级选项与已验证范围

“导入已认可标定（高级）”仅用于旧版已经含 UV3 根梢标定和末尾效果子网格的网格。普通新发型不要勾选。

已验证小 Kaguya 认可版，以及爱莉上的 Ribbon Twintail、H20 侧编丸子盘发、Pure 长发的主发网格：实际多角度渲染、开关绑定、MA 参数/菜单合并及原始网格数据保留。并不代表所有发型、所有 Shader 或商品所有变体均已验证。

插件包不含上述第三方角色/发型的网格、材质或贴图。
